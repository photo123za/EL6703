# ระบบบริหารจัดการคำสั่งซื้อและคลังสินค้าหน้าร้าน (Point of Sale and Inventory Management System)
**งานที่ 2: ระบบบริหารจัดการคำสั่งซื้อและคลังสินค้าหน้าร้าน**

เว็บแอปพลิเคชันระบบขายหน้าร้าน (POS) และระบบจัดการคลังสินค้าแบบเรียลไทม์ พัฒนาด้วย React และ Material-UI (MUI v5) ตรงตามข้อกำหนดและเงื่อนไขทุกประการ

---

## 🌟 ฟังก์ชันการทำงานตามข้อกำหนด (Requirements Checklist)

### 1. การจัดการรายการสินค้าและสต็อก (Inventory Control)
- [x] **แสดงรายการสินค้าพร้อมจำนวนคงเหลือ**: แสดงรูปภาพ ชื่อ หมวดหมู่ ราคา จำนวนสต็อกคงเหลือ
- [x] **การเตือนสินค้าใกล้หมด (Low Stock Warning)**: หากสินค้าชิ้นใดมีจำนวนคงเหลือน้อยกว่า 5 ชิ้น ระบบจะแสดงป้ายเตือน `⚠️ ใกล้หมด (เหลือ < 5)` พร้อมขอบการ์ดสีส้มเด่นชัด และมีแถบแจ้งเตือนรวมด้านบน
- [x] **ตัดสต็อกสินค้าในระบบแบบเรียลไทม์**: เมื่อทำการชำระเงินสำเร็จ สต็อกจะถูกตัดทอนทันทีในระบบ และคำนวณสัดส่วนใหม่ทันที

### 2. การคำนวณคำสั่งซื้อและส่วนลด (Transaction Calculation)
- [x] **คำนวณราคารวม**: คำนวณยอดรวมตามสินค้าที่เลือกและจำนวนชิ้นแบบไดนามิก
- [x] **การประยุกต์ใช้โค้ดส่วนลด (Discount Code)**:
  - `SAVE10` (ลด 10%)
  - `SALE15` (ลด 15%)
  - `DISCOUNT50` (ลด 50 บาท)
  - `VIP20` (ลด 20%)
  - มีปุ่ม Quick Chips สำหรับคลิกเลือกโค้ดส่วนลดได้ทันที
- [x] **คำนวณภาษีมูลค่าเพิ่ม (VAT 7%)**: คำนวณจากยอดหลังหักส่วนลดอย่างถูกต้อง
- [x] **คำนวณเงินทอนและแสดงสถานะเงิน**:
  - ตรวจสอบยอดเงินที่รับ (Cash Received) เทียบกับยอดรวมสุทธิ (Grand Total)
  - คำนวณเงินทอนอัตโนมัติ (พร้อมปุ่มลัดระบุเงินสด 100, 500, 1,000 หรือยอดพอดี)
  - หากเงินไม่พอ แสดงสถานะเตือนว่ายังขาดอีกกี่บาท และล็อคปุ่มชำระเงิน
- [x] **แสดงใบเสร็จรับเงินย่อ (Mini Receipt)**:
  - แสดง Popup Dialog รูปแบบใบเสร็จรับเงินย่อ (Tax Invoice ABB)
  - มีข้อมูลร้านค้า เลขประจำตัวผู้เสียภาษี เลขที่ใบเสร็จ วันที่-เวลา
  - ตารางรายการสินค้า ราคา ยอดรวม ส่วนลด VAT 7% เงินที่รับ เงินทอน
  - มีปุ่ม "พิมพ์ใบเสร็จ" (Print) รองรับการสั่งพิมพ์จริง

### 3. การควบคุมสถานะการขาย (Status Control)
- [x] มี **Switch** สำหรับเปิด-ปิดการจำหน่ายสินค้าแต่ละรายการได้ทันที
- [x] เมื่อปิดจำหน่าย สินค้าจะมีสถานะ "งดจำหน่าย" การ์ดจะถูกลดความเข้มลง และปุ่มเพิ่มลงตะกร้าจะถูกล็อคทันที

## 🚀 วิธีการนำขึ้นแสดงบน GitHub Pages (Deployment Guide)

ไฟล์ `index.html` นี้ถูกออกแบบมาให้เป็น **Single-Page Application (SPA)** แบบ Standalone จึงสามารถนำขึ้น GitHub Pages ได้ทันทีโดยไม่ต้องรัน Build script ใดๆ!

### วิธีที่ 1: อัปโหลดผ่านหน้าเว็บ GitHub (ง่ายและเร็วที่สุด - ไม่ต้องติดตั้งโปรแกรม)
1. เข้าไปที่ [GitHub.com](https://github.com) และเข้าสู่ระบบ
2. กดปุ่ม **New** (สร้าง Repository ใหม่)
   - ตั้งชื่อ Repository เช่น `pos-inventory-system` หรือ `EL67`
   - เลือกเป็น **Public**
   - กด **Create repository**
3. ที่หน้า Repository ที่เพิ่งสร้าง ให้คลิกที่ข้อความ **"uploading an existing file"**
4. ลากไฟล์ `index.html` และ `README.md` ไปวางลงในกล่องอัปโหลด
5. กดปุ่มสีเขียว **Commit changes**
6. ไปที่แท็บ **Settings** ของ Repository -> เลือกเมนู **Pages** (ทางซ้ายมือ)
7. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** (หรือ **master**) และเลือกโฟลเดอร์เป็น **/ (root)**
   - กดปุ่ม **Save**
8. รอประมาณ 1-2 นาที รีเฟรชหน้า จะปรากฏ URL เว็บไซต์ของคุณ เช่น:
   `https://<your-username>.github.io/<repository-name>/`
   สามารถคลิกเข้าชมเว็บไซต์ที่ออนไลน์ได้ทันที!

---

### วิธีที่ 2: อัปโหลดผ่าน Git CLI (หากมีโปรแกรม Git)
```bash
git init
git add .
git commit -m "Initial commit: POS & Inventory System with MUI"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```
จากนั้นเข้าไปเปิดใช้งาน GitHub Pages ใน Settings -> Pages เช่นเดียวกัน
